# 截图

README 引用的两张图都放在这个目录：

| 文件 | 内容 | 建议尺寸 |
|---|---|---|
| `screenshot.png` | 歌词本体（原文 + 翻译 + 下一句，KTV 渐变） | 宽度 800~1200 |
| `menu.png` | 右键菜单全展开 | 宽度 270 |

## 重新截图时的注意

- 用 `Win + Shift + S` 截图，**只框住歌词和菜单本身**，不要带上整个桌面——容易暴露个人信息（歌单、文件名、聊天窗口、播放器账号名）
- 歌名/歌手建议挑一首正常的、跟本项目无关的歌，别用可能会泄露私人歌单的曲目
- 放进本目录后，README 里的相对路径不用改：

```markdown
![歌词效果](docs/screenshot.png)
<img src="docs/menu.png" alt="右键菜单" width="270">
```
